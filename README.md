# holz_python_logger

### Параметры

```
PROJECT_NAME: string - название проекта

LOG_LEVEL: string - уровень логирования (например, 'DEBUG')

LOGSTASH_HOST: string - LOGSTASH хост 

LOGSTASH_PORT: int - LOGSTASH порт 

ENVIRONMENT: string - название среды 

ASYNC_LOGGER: bool - нужно ли использовать асинхронный логгер 
```
